# 肤色检测服务使用说明

## 功能介绍
本服务使用OpenCV进行面部检测和肤色分析，为汉服推荐系统提供准确的肤色类型判断。

## 技术实现
- **面部检测**: 使用OpenCV的Haar级联分类器检测面部
- **肤色分析**: 基于HSV颜色空间分析面部区域的颜色特征
- **API接口**: 提供RESTful API供前端调用

## 安装依赖
```bash
pip install -r requirements.txt
```

## 启动服务
```bash
python skin_detection_server.py
```

服务将在 `http://127.0.0.1:5001` 启动

## API接口

### 肤色检测接口
- **URL**: `/api/skin_detection`
- **方法**: POST
- **请求格式**: JSON
- **参数**:
  - `image`: base64编码的图片数据

### 健康检查接口
- **URL**: `/health`
- **方法**: GET
- **返回**: 服务状态

## 肤色分类
- **暖黄皮**: 色相在0.1-0.2之间，饱和度>0.2
- **冷白皮**: 色相在0-0.1之间，明度>0.7
- **通用**: 其他情况

## 使用示例
1. 启动后端服务: `python skin_detection_server.py`
2. 在前端上传照片进行肤色检测
3. 系统自动分析并返回肤色类型
4. 肤色类型自动应用到汉服推荐中

## 注意事项
- 确保照片中包含清晰的面部
- 光线条件会影响检测结果
- 建议使用正面照片以获得最佳效果
